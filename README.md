# FreeGameHub

A mobile-friendly Android game directory website.

## Important
Only add games you own, games licensed for redistribution, or official/authorized download links. Do not upload or distribute pirated, cracked, or modified commercial APKs without permission.

## Files
- `index.html` — homepage
- `style.css` — design
- `script.js` — game data, search and categories
- `game.html` — game detail page

## Publish with GitHub Pages
Repository → Settings → Pages → Deploy from a branch → `main` → `/(root)` → Save.
